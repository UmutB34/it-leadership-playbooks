# Method note 6: Designing a security awareness and phishing-simulation program

*How I design this kind of program. No organization, participant, result or supplier is described.*

## Goal

Awareness training that an auditor accepts and that actually changes what people do. It runs regularly, is tracked, covers new joiners, and is tied to real attacks such as phishing.

## Design

| Element | Decision |
|---|---|
| Content | Short and practical: passwords, mail, remote access, data sharing, how to report a suspicious message. Reviewed every year with an owner outside IT |
| Frequency | Once a year for everyone, plus an assignment in the first week for new joiners |
| Tracking | Assignments and completion tracked on a learning platform; automatic assignment for new users; reminders; a report to the line manager for people who have not completed it |
| Behaviour | Phishing simulation with realistic test messages and a one-click report button; participation and report rates reviewed |
| Language | Content and reports in the working language, with an English version of the report for audit |
| Evidence | Invitation, attendance or completion list, content, simulation report, stored where the auditor expects them |

## Principles

- **Make completion automatic.** If a person must remember to sign up, the program fails.
- **Keep sessions short and concrete.** Show a real fake e-mail, not a policy.
- **Report to line managers**, not only to HR. It changes behaviour.
- **Tie simulation to learning, not blame.** Nobody is named in a report to the board.
- **Delegate delivery, keep ownership of content.**

## Measuring

| Measure | Use |
|---|---|
| Completion within the deadline | Program health |
| Report rate in simulations | Behaviour that matters |
| Repeat clickers over time | Where to focus |
| Time from receipt to report | Speed of the human sensor |

## Ways to mature it

- Role-based modules for the roles that attract targeted attacks (finance, HR, assistants).
- A short quarterly note between the yearly sessions.
- Tabletop exercises for the people who would act in a real incident.

## Checklist

- [ ] Yearly session plus first-week assignment for new joiners
- [ ] Automatic assignment and completion tracking
- [ ] Reminder rules and a manager report
- [ ] Phishing simulation with a report button
- [ ] Evidence folder with the four items above
- [ ] A yearly content review with an owner outside IT
