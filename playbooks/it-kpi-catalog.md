# IT KPI catalog

*A reusable list of indicators and the fields that make each one auditable. Targets are illustrative.*

## Fields for every KPI

| Field | Purpose |
|---|---|
| Document code and revision | Version control of the list itself |
| Process | Which process the KPI belongs to |
| Unit of measure | Percent, hours, count, date |
| Measurement platform and tool | Where the number comes from |
| Owner | One accountable person or unit |
| Target value | What good looks like |
| Measurement frequency | Monthly, quarterly, yearly |
| Actual value | Filled in at each review |
| Critical success factor | Why the KPI matters |
| Action | What happens if the target is missed |

## Example indicators

| Area | KPI | Unit | Typical target |
|---|---|---|---|
| Availability | Hours of unplanned downtime of critical services | Hours per year | 0 |
| Security operations | Continuity of the monitoring and response service | Percent of year | At the contract level |
| Resilience | Database high-availability project live; unplanned data loss | Date; count | On date; 0 |
| Business applications | ERP and workflow modules live by the planned date | Date | On date |
| Recovery | Annual recovery exercise completed with a report | Yes or no | Yes |
| Service desk | First response and resolution within target | Percent | 90 percent or better |
| Endpoints | Patch compliance within target time | Percent | 95 percent |
| Security awareness | Training completed by new joiners in week one | Percent | 100 percent |
| Cost | Operating and capital spend against budget | Percent | Within plan |
| Vendors | Contracts renewed before the notice date | Percent | 100 percent |

## Choosing well

- Prefer outcomes to activities.
- Keep the card short. Each extra KPI weakens the rest.
- Take evidence from systems, not from a spreadsheet someone fills in.
- Pair every delivery KPI with a stability KPI.
- Link KPIs to company-level themes (for example risk, governance, environment) when the organization reports on them.

## Review rhythm

A short monthly check, a quarterly review with the owner, and a yearly reset with leadership.
