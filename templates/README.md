# Templates

Plain files you can download and adapt. They contain no organization data.

| File | Use |
|---|---|
| `it-budget-template.csv` | Budget lines with a cost driver, owner and contract end date |
| `it-kpi-sheet.csv` | KPI definitions with formula, target, owner and source |
| `change-request-template.md` | One-page change request with rollback and approval |
| `vendor-review-checklist.md` | Checklist for reviewing a supplier contract |

Open the CSV files in any spreadsheet tool.
